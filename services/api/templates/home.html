本地工作台

DeFi Security Agent MVP

这是当前项目的统一入口。你可以直接提交审计任务、研究任务、深分析任务和链上监控任务， 系统会把结果归档，并提供详情页与工件预览。

审计闭环可用 研究工作流可用 链上索引可用 工件归档可用

使用提示

  • 审计任务适合输入本地 Solidity 文件、协议目录，或后续接入的链上地址。
  • 研究任务现在优先按“历史攻击事件 ID”运行，系统会先同步链上证据，再决定是否允许生成可靠研究稿。
  • 只有证据门禁通过，系统才会进入最终研究稿生成；证据不齐时会明确阻断，而不是凑结果。
  • 建议勾选“保存工件”，这样每次运行都会生成可回看、可验收的归档目录。
  • “历史工件”支持直接打开详情页，也支持在首页预览 Markdown 与 JSON 工件。
