## 1. Ethena USDe ($5.9B) — CEX 对手方风险 🔴

### 核心架构
Ethena 通过持有 stETH + 在 CEX 做空 ETH 永续合约来创建 USDe 合成美元。sUSDe 是质押版本，在 Aave/Morpho 中作为抵押品使用。

### 链上验证

| 指标 | 值 |
|------|---|
| USDe 总供应量 | ~59.2 亿 |
| sUSDe 总资产 | ~35.9 亿 USDe |
| sUSDe 份额价格 | 1 sUSDe = 1.2236 USDe |
| sUSDe 冷却期 | **7 天** |
| 储备基金余额 | **$41.9M** (主要是 USDtb) |
| 储备/供应比 | **0.71%** ⚠️ 严重不足 |
| 合约可升级 | **否** (非代理模式) ✅ |
| 所有者 | 5/11 Gnosis Safe 多签 |

### 关键风险

**1. 储备基金严重不足 (0.71%)**
- $41.9M 储备 vs $5.9B 供应量
- CryptoQuant 警告：储备仅在 USDe 市值低于 $4B 时可持续
- 2025 年 10 月负 funding rate 导致 USDe 供应从 $14.3B 骤降至 $7.05B

**2. CEX 对手方风险 — 链下不可验证**
- 空头头寸分布在 Binance、Bybit、OKX、Deribit
- 链下对冲仓位**无法在链上验证**
- 2025 年 10 月 Binance Oracle 故障导致 USDe 在该交易所跌至 $0.65

**3. sUSDe 级联清算风险 — 系统性传染**
- sUSDe 在 Aave 上抵押品峰值达 $4.7B
- USDe 脱锚 → sUSDe 价值下降 → Aave 清算 → 清算卖压加剧脱锚 → 反身性螺旋
- Aave 共享池设计无法隔离此风险

**4. 铸造权限中心化**
- 5/11 多签控制所有核心合约
- 可更改 USDe minter 至任意地址 → 无限铸造
- **无时间锁观察到**

### 攻击可行性

| 攻击向量 | 可行性 | 影响 |
|---------|--------|------|
| DEX 强制脱锚 (~$90M 抛售) | 中 | 高 — 链上流动性仅 ~$70M |
| 5/11 多签妥协 | 低 | 致命 — 可无限铸造 USDe |
| 持续负 funding rate | 中 | 高 — 储备金不足以覆盖 |
| sUSDe 在 Aave 级联清算 | 中 | 致命 — $4.7B+ 敞口 |

## 2. JustLend ($3.16B) — 极端中心化 🔴

### 核心发现

JustLend 是 Tron 上的 Compound V2 Fork，**TVL 数字具有高度误导性**。

**治理形同虚设:**
- Timelock 合约自 2020 年部署以来仅有 **9 笔交易** (5年+)
- GovernorBravo 自 2022 年仅 **83 笔交易**
- 相比之下，Compound 的 Timelock 每年处理数十笔
- 说明协议参数变更绑过治理或治理基本不活跃

**TVL 集中度惊人:**
- 98.7% 的 BTC 供应来自 3 个钱包
- 99.7% 的 stUSDT 供应来自单一来源
- Justin Sun 据报控制 85% stUSDT (通过 HTX)

**stUSDT 循环依赖:**
```
用户存入 USDT → HTX → 转换为 stUSDT (声称 RWA 收益)
→ stUSDT 存入 JustLend → JustLend 报告为 TVL
→ HTX 报告 stUSDT 为储备 → 循环放大
```
ChainArgos 调查发现 stUSDT 资金并未实际投资 RWA

**Bug Bounty 严重不足:**
- 最高赏金 $50K vs $3.16B TVL = **0.0016%**
- 以 USDD (算法稳定币) 支付
- 行业标准：Compound $150K, Aave $250K, MakerDAO $10M

**无暂停机制:**
- 团队已将 Guardian 角色放弃至零地址
- 发生漏洞利用时**无任何紧急刹车**

### 风险评估

| 类别 | 评级 |
|------|------|
| 智能合约风险 | 中 (Compound V2 代码经过检验) |
| 中心化风险 | **致命** |
| 系统性/对手方风险 | **致命** (Justin Sun + HTX + stUSDT) |
| 治理风险 | **高** (形同虚设) |
| Tron 平台风险 | 中 (27 个 SR, 可审查交易) |

## 3. Maple Finance ($2.3B) — 零首损资本 🔴

### 链上验证：所有活跃池首损覆盖为零

| 池 | 总资产 | PoolDelegateCover 余额 |
|---|--------|----------------------|
| syrupUSDC | $1,730.6M | **$0** |
| syrupUSDT | $933.7M | **$0** |
| Secured Lending | $83.3M | **$0** |

**这是最关键的链上发现。** 三个活跃池管理 $27 亿资产，但链上首损资本为零。所有信用损失 100% 由存款人承担。

### 核心风险

**低抵押贷款 — 不可消除的信用风险:**
- 贷款给机构借款人，无完全链上抵押品
- 2022 年 Orthogonal Trading 违约 $36M (80% 损失率)
- 当前 Pool Delegate 可将贷款发放给同谋方，默认后损失全归存款人

**治理:**
- DAO 多签 4/7, 安全多签 3/6, 运营多签 3/5
- 时间锁延迟**无法独立在链上验证** (函数签名不匹配)
- 所有签名者为匿名 EOA

**提款风险:**
- 基于队列的提款管理器 — 非即时
- Impairment (减值) 机制可冻结提款并强制损失

## 5. Compound V3 ($1.29B) — 代理升级全损风险 🟠

### 核心发现

**V3 架构使治理攻击更简单、更致命:**
- 所有资金 (基础代币 + 所有抵押品) 集中在单个代理合约中
- 治理可通过 `CometProxyAdmin.upgrade()` 将代理指向**任意合约**，绕过 Configurator
- 恶意实现可一笔交易提取全部资金

**Proposal 289 实证 (2024-07):**
- 鲸鱼 "Humpy" 通过积累 COMP 投票权，成功通过了从国库转移 $24M 的提案
- 仅通过链下谈判阻止，无任何技术手段
- 证明治理捕获在经济上可行

### 链上状态

| 市场 | 总供应 | 总借款 | 利用率 | 储备金 |
|------|-------|-------|--------|-------|
| USDC | $412M | $268M | 64.99% | $14M |
| WETH | 30,687 ETH (~$63M) | 28,679 ETH | **93.45%** ⚠️ | 948 ETH |

**WETH 市场 93.45% 利用率** — 仅 ~2,008 ETH ($4.1M) 可提取。大额提款将被阻塞。

### 缺失的防御机制

| 防御 | 存在? |
|------|:-----:|
| 备用 Oracle | ❌ |
| 价格边界/熔断器 | ❌ |

## 6. Pendle Finance ($2.2B) — Oracle 集成风险 🟡

### 核心发现

**治理中心化:**
- 所有核心合约由 **3/5 Gnosis Safe** 多签控制
- Dev 多签仅需 **2/5** 签名
- **无时间锁** — 变更可即时生效
- 同一组 5 个签名者控制两个多签

**PT Oracle 对下游协议的影响:**
- Aave 上已有 $1.6B+ PT 代币作为抵押品
- PendlePtOracle 使用 TWAP，大市场 (>$10M) 操纵不可行
- **低流动性市场 (<$1M) 可被操纵** — 15 分钟持续操纵可影响 TWAP

**历史事件: Penpie ($27M, 2024-09)**
- 攻击者创建假 Pendle 市场 + 恶意 SY 代币
- 利用 Penpie 的重入漏洞提取 $27M
- **Pendle 核心未受影响**，但证明无许可市场创建的风险

### Oracle 防闪电贷验证

| TWAP 时长 | PT-to-Asset 价格 | 闪电贷影响 |
|-----------|-----------------|-----------|
| 1 秒 | 0.989304978934924064 | - |
| 900 秒 (15分) | 0.989304978934924064 | <0.02% |
| 1800 秒 (30分) | 0.989304478175599095 | <0.00005% |

闪电贷对 15 分钟 TWAP 的影响可忽略不计。

## 7. SparkLend ($1.96B) — MakerDAO 绑定风险 🟡

### 核心发现

**三重 Oracle 是行业领先:**
```
SparkLend 使用 Aggor 聚合器:
  1. Chronicle (MakerDAO 原生 Oracle, ~22 验证者)
  2. Chainlink (行业标准)
  3. RedStone (2025 年新增)

→ 同时攻破三个独立 Oracle 网络几乎不可能
```

**D3M/Allocator 深度耦合:**
- MakerDAO 直接向 SparkLend 铸造 USDS (凭空创造)
- 当前未偿 USDS: ~$2.92B (上限 $3.56B, 利用率 82%)
- SparkLend 与 MakerDAO 之间的双向依赖意味着任一方失败都会传播

**固定价格 Oracle 风险:**
- DAI 定价为 $1.00 (固定, 非市场价)
- 若 DAI 脱锚至 $0.85 → 攻击者以 $0.85 购入 DAI → 在 SparkLend 以 $1.00 存入 → 借出 ETH/BTC → 提取 15% 利润

**Fork 版本滞后:**
- SparkLend Fork 自 Aave V3 v3.0.2
- Aave 当前已到 v3.6 — SparkLend 可能缺少重要安全补丁
- 已确认应用：flashloan-to-borrow 修复 (2024-04)

## 8. Kamino Lend ($2.0B) — Solana 最佳实践 🟢

### 核心发现

**安全记录最佳:**
- 18+ 独立审计, 4 次 Certora 形式化验证
- **$0 坏账** — 经历 5 次 20%+ SOL 暴跌, $120M+ 清算, 零坏账
- $1.5M Bug Bounty (Solana 最大)

**程序升级权限 (链上解码):**

| 参数 | 值 |
|------|---|
| 多签类型 | Squads v4 |
| 阈值 | **5/10** |
| 时间锁 | **12 小时** |
| 成员数 | 10 (全权限) |
| 已执行提案 | 63 次升级 |
| 配置权限 | 已禁用 |

**Oracle 架构 (Scope 聚合器):**
- 多源: Chainlink Data Streams + Pyth + Switchboard

## 审计方法论

```
每个协议审计流程:
  1. 架构分析: Fork 来源、核心合约、治理链
  2. 链上验证: cast call / Solana RPC 查询实际合约状态
  3. Oracle 评估: 价格源、陈旧检查、操纵抗性
  4. 治理分析: 多签配置、时间锁、攻击成本
  5. 历史事件: 过往攻击、漏洞、事故复盘
  6. 攻击可行性: 成本/收益分析、现实约束
  7. 诚实结论: 区分理论风险 vs 可执行攻击
```
